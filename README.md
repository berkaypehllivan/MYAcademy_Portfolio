# MYAcademy Portfolio

ASP.NET Core MVC ile geliştirilmiş, veritabanı destekli, tamamen yönetilebilir kişisel portfolyo uygulaması. İçerikler (Hakkımda, Eğitim, Deneyim, Yetenekler, Projeler, Mesajlar) admin panelinden yönetilir ve public sayfaya anlık olarak yansır.

## 🚀 Kullanılan Teknolojiler

- **Backend:** ASP.NET Core MVC, Entity Framework Core (Code First)
- **Veritabanı:** MSSQL
- **Frontend:** Bootstrap 5, Boxicons, Inter (font)
- **Admin UX:** SweetAlert2 (silme onayı, bildirimler)
- **Mimari:** Area tabanlı yapı (`Admin` alanı), dosya yükleme (profil görseli, CV, proje kapak görseli), ilişkili tablo yönetimi (kategori — proje)

---

## 🏠 Anasayfa (Public)

Ziyaretçilerin gördüğü, tamamen veritabanından beslenen açık/aydınlık temalı portfolyo sayfası.

**Öne çıkan özellikler:**
- Dinamik Hakkımda bölümü (isim, unvan, tanıtım metni, profil görseli, iletişim bilgileri)
- Eğitim ve Deneyim zaman çizelgesi — yalnızca aktif kayıtlar görüntülenir
- Teknoloji/araç etiketleriyle Yetenekler bölümü
- Kategoriye göre filtrelenebilir Proje kartları
- Çalışan CV indirme butonu
- Veritabanına kaydedilen İletişim Formu

## ⚙️ Admin Panel

Tüm içeriğin yönetildiği, giriş gerektiren yönetim paneli.

**Öne çıkan özellikler:**
- **Dashboard:** Toplam proje, aktif proje, yetenek, deneyim, eğitim, mesaj ve okunmamış mesaj sayıları; son mesajlar, son projeler ve kategori özeti
- **Hakkımda Yönetimi:** Profil bilgileri, profil görseli ve CV (PDF) yükleme/güncelleme
- **Eğitim / Deneyim / Yetenekler / Projeler:** Tam CRUD işlemleri, aktif/pasif durumu, manuel sıralama (yukarı/aşağı taşıma)
- **Kategori Yönetimi:** Projelerle ilişkili kategori ekleme/silme
- **Mesajlar:** Okundu/okunmadı durumu, gönderene veya konuya göre arama, tarihe göre sıralama, okunmamış mesaj sayacı, detay modalı ve hazır yanıt modalı
- **Dosya Yönetimi:** Görsel ve PDF yüklemelerinde tür/boyut doğrulaması, eski dosyanın otomatik silinmesi
- **SweetAlert2** ile silme onayları ve işlem bildirimleri
